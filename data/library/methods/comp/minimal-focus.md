# 大留白 + 单主体（章节题/金句段的默认公式）

一张画面只讲一件事：**一个主角 + 大量呼吸空间**。参考片的开场、章节题、金句卡全是这一式。

- 主体占画面 40–55%（大 big/大 icon/单一 image），**不要**再叠第二视觉锚点；解说文字最多一行。
- 主体放画面几何中心±10%，四周留白至少各 20%；元素数压到 2–3 个（下限已放宽时也要忍住）。
- 层次用"大小对比"拉开：主体 ≥280px，辅助小字 ≤48px，**没有中间档**——中间档是"信息卡片感"的来源。
- 颜色只用两级：底色 + 主色（或 ink），accent 至多出现在一个字符/一条线上。
- 动效克制：主体一个 pop/rise 入场即可，禁止多元素连番入场抢注意力。

反模式：金句 + 引号图标 + 装饰线 + 作者名 + 边框五件套同屏——那是 PPT 封面，不是章节题。
