# MV 剪辑节奏与直喻（来自 B 站高播 MAD 拆解）

适用：歌词 MV、卡点 PV、宣传片、任意"音乐/旁白驱动"的片子。四条主干规则：

1. **直喻配图**：抽象词句不配"相关图"，配"直喻图"——唱"争夺"给两只斗殴的猫，唱"被挂上门锁"
   给门锁特写。在 spec 里 = 把这句的意象名词抽出来当元素主体，入场词序 = 该词出现的词号，
   让观众感到"画面在替歌词说话"。
2. **暗场标点**：情绪重的句子前后插近黑帧，帧上只留一个亮点（一双眼睛、一盏灯、一行字）。
   语法里 = scrim 压到 0.85+ 或纯黑底 + 单个 icon/短句，时长 0.5–1s。黑场是标点符号，不是事故。
3. **呼吸镜头**：段落边界的镜长放大 2–3 倍——大色块空镜 + 极小主体（花田里一个远景小人），
   让密集信息段有地方换气。对应分段片：章节首尾各留一个"只有背景+一句话"的段。
4. **首尾呼应**：结尾复用开场那一镜（同主体同构图），只改一处参数（更暗/更远/少了什么），
   全片立刻"闭环"。分镜表里记下第一段的主体与位置，最后一段显式引用。

节奏参考值（实测）：卡点段镜长 0.5–1s，叙事段 2–4s，段落边界 4–6s；全片剪切密度在段落间
要做"密→疏"呼吸，不要匀速。配色按章节切主色相（白天暖黄 ↔ 夜蓝），全片交替不超过两组。

反模式：全程 0.3s 匀速闪切（观众 20 秒后疲劳）；直喻图与词义无关只求"好看"；黑场连用超过两次；
副歌每段换一套配色。
