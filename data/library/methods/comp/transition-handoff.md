# 段间衔接公式（让分段片看起来像一整部）

每段独立成页，但观众要感到"连续"——三招在 spec 层就能做：

1. **段首不抢拍**：黑场淡入是渲染层统一加的（0.25s），所以段首主元素 reveal 放在词序 1–2，
   别 0 号词就满屏元素齐现；首个元素入场用 fade/rise 顺应淡入方向。
2. **段尾留白收束**：讲完的内容用 exit 提前退场（exit 词序 = 该内容讲完的词号），
   让最后一句旁白落在"接近空的画面"上——黑场淡出接得干净，不切头。
3. **跨段接力**：本段最后一个视觉元素与本段开场的下一个主体**同 kind、近似位置**
   （如上段结尾右下角一颗发光 icon，下段开头同位置放大成主体）——观众的视线不动，
   "跳段感"就消失。分镜的 chapter 字段相邻同名段自动视为一章，章内必做接力。

反模式：段尾所有元素赖着到最后一帧（淡出时画面正满 → 段间像断电）；段首 0 号词连环 pop 五个元素。
