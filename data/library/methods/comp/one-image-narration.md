# 一图流自述片（最省素材的成片公式）

适用：自述、告别、感谢信、独白、宣言类 60–90s 成片。源自 B 站 62 万播放的漫画告别片
（全片 62s 零剪切，只有一张插画）：

1. **一张插画扛全片**：白底/纸底 + 单张居中插画（四周留白 ≥15%），全片 0 剪切，
   只做镜头内运动——缓慢 zoom 5–8% 或轻微上下 bob 循环。观众不会腻，因为**字幕是主角**，
   插画只负责情绪定调。
2. **字幕叙事**：底部常驻、逐句替换、一次一句不超两行；插画动效与字幕节奏解耦
   （插画循环走它的，字幕按旁白切它的）。
3. **黑场收尾**：内容讲完 → 切纯黑 + 一行字（"谢谢"/落款/日期），静置 2s 再淡出。
   收尾越安静，越显诚恳。
4. **BGM 克制**：轻器乐循环，人声出现时自动 duck；全片音量动态只有"进人声"这一件事。

适合我们的场景：用户只提供一段文稿 + 一张图（或无图用单色底）时的兜底成片法——
零分镜成本、零素材风险，且完成度显著高于"硬排三段文字"。

反模式：中途换插画（打破沉浸，除非内容分章）；字幕三行以上；白底配灰字（对比度）；
插画放大到顶满画面（失去"纸上画作"的体面感）。
