# 数据卡片语法（来自小Lin说 774 万播财经拆解）

适用：财经解读、数据科普、对比评测，任何"要讲一个数字故事"的段。五条主干：

1. **图表卡**：白底大卡片占画面 60–70%，只画一条主线（红降蓝升二选一做语义色），
   关键拐点钉"标签贴片"——圆角小色块 + 白字 3–5 字（如「经常账户」），全片贴片
   同色同义。语法里 = 白卡元素 + SVG/canvas 折线 + 2–3 个标注点，别超过两条线。
2. **章节卡**：黑底满屏 + 金色衬线大字 2–4 字（如「汇率」），下方同主题英文小字，
   四周排一圈主题符号小方格（货币符/图标）当边框，静置 2–3s 当"章回标题"。
   每次换概念换一张，全片 3–5 张。
3. **概念卡组**：深色底 + 同构卡片横排 3 张（如经常/资本/金融账户），每卡 = 图标 +
   中文名 + 英文小字；讲到哪张点亮哪张（其余压暗 40%），逐张点亮就是叙事进度条。
4. **数字特写**：结论性数字单独满屏一瞬（超大字 + 单位 + 一行注脚），前留半秒黑场
   或虚化铺垫，让数字"砸"出来。
5. **讲解窗**：真人/头像永远圆形小窗压在角上（直径 ≤22% 画高），不挡卡片主体；
   无人声段才放全屏图表。

节奏参考值：图表卡 6–10s，章节卡 2–3s，数字特写 1–2s；一段只讲一张卡的事。

反模式：一张图塞三条折线（观众读不完）；贴片颜色随机换（同义异色）；卡片铺满全屏
不留边；章节卡当转场频繁用（它是章回不是过场）；数字特写连用（第二次就不"砸"了）。
