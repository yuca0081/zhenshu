# 步骤流程+UI复刻标注（来自大瑞真机灵《驾照隐藏用法》110 万播拆解）

适用：办事指南/软件教学/操作流程，"照着做就能办成"的教程段。实测：80s 22 切点
（0.28/s），Q 版主持人串场 + UI 贴片讲步骤。四条主干：

1. **步骤编号**：流程切步骤时压编号大字（「2 到期想换证」），编号+短句白底黑字
   置左上；全片步骤 ≤4 步，一步一个 UI 贴片。
2. **UI 复刻贴片**：真实界面用 CSS 复刻（列表页/表单页/详情页），保真度到"看得清
   每个入口图标"；要点的那个按钮/入口用**红框+放大 10%** 标注，观众视线直接落点。
3. **主持人锚位**：讲解形象固定在画面一侧（约 30% 宽），只换姿势不换位；UI 贴片
   出现时主持人缩到边角或不出现，绝不遮贴片。
4. **结果前置**：开场 5 秒先给最终效果（驾照生成/办结画面），再回头讲步骤——
   "先看到终点，人才愿意跟着走"。

节奏参考值：单步 6–10s（贴片出现后至少停留 4s 让人看清）；步骤间用主持人半身镜
过渡 1–2s；片尾用假推荐流贴片（竖屏封面×4+红字「这些精彩」）做导流。

反模式：一屏塞两个 UI 贴片（看不清标哪个）；红框超过一处（没有落点）；贴片模糊
保真度低（可信度崩）；主持人遮住贴片关键区域；步骤没有编号（观众迷路）。
