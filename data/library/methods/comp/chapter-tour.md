# 章节巡礼长镜（来自珑师傅《秦汉纹样》302 万播拆解）

适用：文化/艺术/工艺/历史科普，"一个主题拆多个子项逐个看"的系列内容。实测：
231 秒全片只有 4 个切点（0.02 切/s，中位镜长 19.5s），靠镜头内运动推进。四条主干：

1. **一张底焊全片**：宣纸/布纹/暗纹水印打底（约 5% 透明度），所有章节共用同一张
   底，异质素材（照片/插画/图卡）被纹理焊成一体。语法里 = bg.fx 用 noise + 低透明
   水印层，全片不换底色。
2. **章节大字锚点**：每章开头顶部压黑体大字（4–6 字 + 细描边投影），一章一个主题
   词（如「云气纹」「博局纹」），锚点字风格全片一致、只换内容。观众靠它定位进度。
3. **满幅巡礼图**：章内主体 = 满幅或半幅的器物/画作特写，缓慢 pan/zoom/渐显（15–25s
   一景），底部一行白字注解 + 来源小字（馆藏/出处）。信息密度靠"局部特写"堆叠，
   不靠切换。
4. **朱红点缀 ≤2**：每章至多两处正红（印章、红字梗、红色标注线），用在最想让观众
   记住的那一句上；其余点缀色全部让位给底色和主体物。

节奏参考值：章 25–40s，章内单景 15–25s；全片 5–8 章；开场可用一张"全系列定位图"
（地图/谱系）定场后再进第一章。

反模式：章内频繁切镜（巡礼变成幻灯片快闪）；每章换一套底色（焊不住）；红点缀超两处
（失去标点作用）；大字锚点中途换字体/换位置；注解小字压在主体上。
