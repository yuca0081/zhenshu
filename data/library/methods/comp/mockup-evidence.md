# 巨字标点 + 假UI证据（来自队友去质器 453 万播拆解）

适用：热点盘点、讽刺科普、事件解说，"吐槽+证据"结构的段。三条主干：

1. **数字巨字卡**：关键数字单独满屏——黑底 + 特大号白字（数字+单位一行，
   如「90–250公斤」），无其他元素，静置 1.5–2s 当"标点"。一场片子在情绪重句和
   反差处各插一张（≤3 张），比任何转场都硬。
2. **假 UI 证据贴片**：引用"网上怎么说"时用 CSS 复刻的界面贴片当证据——浏览器窗/
   视频站页面/新闻台标横幅，内部填真实引文，配红圈/箭头标注要点。贴片占画面 ≤60%，
   斜切 1–2 度防呆板，一屏一个。
3. **大字幕纪律**：解说字幕 = 底部居中超大白字（≤15 字/行，粗黑描边），全片常驻
   同一位置从不换位；正文素材（截图/照片/图表）都给字幕让出下 1/5 安全带。

节奏参考值：混剪段 1.5–2.5s/镜，证据贴片段 3–5s，巨字卡 1.5–2s；密段后必接疏段
（巨字卡/黑场就是疏段）。

反模式：巨字卡连用两次以上（标点失效）；贴片内容造假引文（证据感崩塌）；字幕随
素材换位置（观众找不到锚）；贴片满屏（证据变成主体）；全程匀速混剪无疏密。
