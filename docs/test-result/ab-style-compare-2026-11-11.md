# A/B 实验：风格库选风格 vs 完全自创风格 —— 画面对比

**日期**：2026-11-11
**目的**：同稿同画幅，对比「风格库条目（真迹锚点）」与「AI完全自创（无锚点）」两条路径的成片画面差距。

## 实验设计

| 变量 | A组 `p20261111-003000` | B组 `p20261111-003000-2` |
|---|---|---|
| 稿子 | 《彩虹为什么是圆的》同稿（约400字） | 同左 |
| 画幅/时长 | 9:16，idea 标注1.5分钟 → target 90s | 同左 |
| 风格来源 | 库条目 vid-ref20261110-234947「傅里叶霓虹波形」锁定 | style_notes 指令完全原创：不选库不衍生，register_style base_id 空 |
| 实际执行 | 模型衍生登记 sp20261111-003130「棱镜光环·光谱推导」（基于锁定条目，样张判卷对照真迹） | 纯自创 sp20261111-125851「四十二度圆环·深空图鉴」（无真迹对照） |
| 场景生成模型 | glm-5.3（seg03 稳定空回）→ 中途切 glm-5.3-flash | glm-5.3-flash（全程） |

## 结果

| 指标 | A组（库风格） | B组（自创） |
|---|---|---|
| 成片 | renders/main.mp4，88.6s / 19.7MB | renders/main.mp4，83.0s / 97.8MB |
| 全片终审 | 通过，折算 **4.0** 分 | 通过，折算 **3.8** 分 |
| 样张 | 1张，**近乎废图**（整帧纯黑只剩角落标签，判卷当时带伤放行） | 2张，完整设计语言页（深蓝底+宋体+金色强调+术语标签体系） |
| scene 生成 | 25次调用 / 366k token | 30次调用 / 503k token（+37%） |
| 波折 | 睡眠看门狗误杀×1、glm-5.3空回×5轮、终审content刹车×1（追加一轮过） | seg11 段审刹车×1 + check三轮未过×1（追加一轮过） |

### 多模态视觉评审（15帧逐帧对比）结论

- **B组整体画面质量更高，系统性优势**：质感细节（星点颗粒/径向渐变/金色辉光/多层彩虹渐变线）、组内一致性（A组 a-82 整帧偏色、a-72 标签不可见）、样张→成片传递（B 明确延续样张语言；A 样张是废图，成片靠真迹锚点约束撑住未崩）。
- A组仅 58s 节点反超（信息最完整一帧）；B组 58s 帧核心元素过暗是最大单帧翻车。
- A组成片只继承了「霓虹细线辉光」，未见波形/频谱元素——真迹贴合度存疑（评审时未提供真迹帧，未比对）。

## 结论与解释（单次实验，不下普遍结论）

1. **有真迹锚点 ≠ 画面更好**。本次自创路径赢在设计执行质量：B组样张阶段产出了完整设计系统并传到成片；A组样张翻车（判卷放行了纯黑帧），设计阶段欠账靠制作阶段的真迹约束兜底。
2. **库风格的价值本次体现在"兜底"**：A组在样张废图的情况下成片仍终审4.0分且风格未崩——真迹锚点（样张判卷对照+简报约束）起了防崩作用，但没能把画面托到更高。
3. **自创路径更贵**：B组 scene token +37%，无设计系统锚定时重写轮次更多。
4. 两片在同一句稿子（「整圈都压到地平线以下」——要画"看不见"）上各撞一次签名刹车：内容难度与风格路径无关。

## 过程中发现的平台缺口

1. **衍生条目简报 Evidence 断链**：锁定库条目后模型衍生登记本片条目，最终 style_brief.json 落衍生条目（Evidence=0帧）——制作阶段真迹注入静默缺失（样张阶段有对照，制作阶段全盲）。修法方向：BriefFrom 对衍生条目回填基风格真迹。
2. **glm-5.3（非flash）场景生成稳定空回**：对特定请求 6秒内3次尝试全部返回空内容（错误显示"原文前200字"为空），重试无效；切 glm-5.3-flash 后同段一次过。scene_gen 工位勿绑 glm-5.3 大杯档（已于本次实验中改回 flash 并保存）。
3. A组样张判卷放行了近乎纯黑的废图样张——判卷对"整帧无内容"型硬伤漏判（blank 判据只看尾帧黑屏？中段废帧未拦）。
