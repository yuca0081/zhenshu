# 帧述 · 项目总览与全景图

> 状态：2026-09-22。本文是全部讨论的汇总视图：一页看懂整个项目。
> 细节以专项文档为准：`plan.md`（产品与架构）、`tech-stack.md`（选型）、`references.md`（开源参考）。

## 1. 项目是什么（三句话）

**聊天框驱动的视频创作网站**：用户把文稿发给 AI，AI 通过对话攒齐"文稿 + 分镜"两份文档，自检通过后自动完成配音、画面生成、渲染，产出可直接发布的科普/解说成片。因为成片是网页代码**确定性渲染**的 MP4，预览即成片，每一帧都可以指着改。

三个卖点：**聊天即创作 / 预览即成片 / 指哪改哪**。

## 3. 生产全流程图（一次创作的完整旅程）

```
 你："这是我写好的稿子，直接做吧"
 │
 ▼
═════════ 阶段一 · Agent 循环（自动串联，到风格图停下等你点头）═════════
  想:先存稿      → save_manuscript     → ✓ 已存（状态:有稿）
  想:该出分镜    → draft_storyboard    → ✓ 9 段（状态:有分镜）
  想:出风格样张  → draft_style_samples → ✓ 1-3 张样张 ⏸ 你点头确认
  想:按规矩自检  → run_selfcheck       → ✓ 三前置齐备通过
  想:那就开工    → start_production    → ✓ 流水线启动
  回你："稿子已存，分镜 9 段，风格你已确认，开工了，进度随时报。"
 │
 ▼
═════════ 阶段二 · 制作流水线（Go 编排，AI 只在三个点动脑）═════════
  [配音]  每段旁白 → 音频 + 逐词时间戳
          （火山 TTS 自带；不行就 funASR 语音识别反打——双路径已获同类项目验证）
      ↓
  [拆包]  每段一个 packet：旁白 + 画面提示 + 风格 + 相关经验卡 + 方法库注入
           （scene 参考实现 / 高级感构图公式，按段内容关键词命中）
      ↓ （段与段并行，互不干扰）
  [写画面] AI 按语义 spec 写每段网页动画：28 种元素——排版卡片、图表、照片，
           也有程序化画布（粒子/弦图/线框3D，同刻必同画）、LaTeX 公式、关键帧运镜；
           每个可见元素必须起人话名（指着改的地基）
           （"箭头：模型→工具"——这是以后指着改的地基）
      ↓
  [质检]  四道闸：契约校验 → lint/check → 四帧视觉审查 → 程序化画布确定性回放
           → 不过就把诊断喂回 AI 定点修，≤3 次
      ↓
  [渲染]  N 段同时渲（无头浏览器逐帧确定性渲染）→ 拼接
  [成片]  统一后期（暗角/颗粒 + BGM 混音 + 转场音效）→ 跨段章节角标/计数器 HUD
      ↓
 整条视频就绪 ── 舞台一次性点亮（不做边渲边显示），时间轴可播放
 │
 ▼
═════════ 阶段三 · 修改循环（指着任何东西说话）═════════
  时间轴点一下某段 / 暂停在某一秒 / 检视模式点选页面里的某个元素
      → 输入框上方出现引用卡 📎 段3 · 00:45.2 ·「箭头：模型→工具」
      → 你接着说："改成珊瑚色，飞慢一点"
      → AI 只改那段代码里的那个元素 → 只重渲那一段 → 时间轴该段更新
  （改得细到元素，重渲永远是段——又快又稳）
 │
 ▼
═════════ 阶段四 · 出片 + 沉淀 ═════════
  "出片" → 1080p 高清渲染（同样段级并行）→ 上传 MinIO → 下载 MP4
  Agent 起草："这套风格存成模板？这次的坑记一条？" → 你点确认 → 入方法库
      ↓
  下次创作：选同款风格 + 经验卡自动注入 → 越用越熟练（飞轮）
```

## 4. Agent 循环图（想 → 做 → 看 → 再想）

```
   你的消息（+ 引用卡 📎）
        ↓
   ┌─▶ 大模型想一步
   │        ↓
   │    要调工具吗？ ──否──▶ 说出回复，循环结束（这段话就是给你的答复）
   │        │ 是                （另外两个出口：转满 10 圈强制总结 / 报错）
   │        ↓
   │    门禁：当前流程阶段允许这个动作吗？
   │        ↓
   │    执行工具，结果追加进上下文（被拒绝也是结果，它自己换路）
   └───────┘
```

代码形态就是一个 while 循环：`发请求给大模型 → 有工具调用就执行并把结果追加回上下文再来一次 → 没有工具调用就结束`。循环在我们 Go 代码里，模型只负责"想"。参考 pi：这样一套核心 400 来行就能做到顶尖水平，不需要任何框架。

## 5. 全部决策速查表

| 板块 | 决定 |
|---|---|
| 产品形态 | 聊天框驱动；左历史（会话中收起）/ 中舞台（文稿→分镜→风格图→视频+时间轴）/ 右聊天 |
| 硬前置门 | **三件**：文稿 + 分镜 + 风格图（用户确认）；齐备 + AI 自检 → 才开工；代码硬检查 |
| 风格图 | AI 用同一套风格参数渲 1–3 张 HTML 样张，用户点头才锁定为 StylePack（所见即所得） |
| 时长策略 | 忠实原文，时长服从内容，硬上限 15 分钟（超限 AI 压缩+协商） |
| 文稿 | 一等产物；来源可插拔（粘贴/链接提取/AI 起草，后两者二期） |
| 默认画幅 | 9:16 竖屏默认，可切 16:9 |
| BGM/音效 | 程序化合成曲库（版权自持，9 首按情绪）+ 转场 sfx（段边界气流/章节上扬），`set_bgm`/`set_sfx` 随时换、秒级重混 |
| 修改自由度 | 段 / 秒 / 帧 / 元素四级寻址；命名元素悬停点选 + 圈选 + 嘴说兜底 |
| 修改 vs 重渲 | 改到元素，重渲到段 |
| 渲染 | HyperFrames 确定性渲染；段级并行 + 拼接；整条完成再展示 |
| Agent | 主管（ReAct 循环 + 工具）+ 无人格技能 + Go 确定性编排；状态机门禁 + 步数≤10 |
| 模型分层 | 对话=便宜快 / 分镜规划=中档 / 画面生成=最强；DeepSeek 主选，M0 三档实测冻结 |
| 方法库 | 模板库（StylePack 成片提炼→确认入库→复用）+ 方法注入（scene 参考实现/高级感构图公式，按段内容关键词命中进 spec 生成，`data/library/methods/` 清单驱动） |
| 对话存储 | chat_messages 追加式事件流（user/agent/system × text/tool_call/progress） |
| 前端 | Vue 3 + Vite + **TypeScript** + Naive UI + Pinia；时间轴自研（三轨只读导航型） |
| 后端 | Go + Gin 单二进制；GORM + PG；jobs 表 + worker 池；SSE 推流 |
| 数据库/存储 | PostgreSQL + MinIO（均在原服务器，跨网接入，防火墙白名单） |
| 部署 | 新服务器独占：app 容器 + renderer 容器（Node22+FFmpeg+锁版 HyperFrames）；服务器 M1 前购买 |
| 产品名 | 后置，「帧述」占位 |
| 阶段路线 | 1.0 自用打通全链路出成品 → 1.x 商业化（多用户/积分/安全加固）；商业化接缝已预埋 |

## 6. 里程碑

| 里程碑 | 内容 | 关键验收 |
|---|---|---|
| **M0 管线打通**（1–2 周，无 UI） | CLI 串起全流程；七项实测（时间戳×2、LLM 三档 bake-off、渲染基线、元素命名、转场拼接、资源占用） | 10 篇真实文章出片 + 耗时/成本/通过率数据 |
| **M1 聊天工作台**（2–4 周） | 新布局 + 舞台四态（文稿→分镜→风格图→视频）+ 三前置硬门 + 整条生成 + 段级重做 + 出片下载 + 方法库第一版 | MVP 验收：粘贴文稿 10 分钟内出 60–90s 成片（时长忠实原文 ≤15min）；10 次生成 ≥7 可用 |
| **M2 精细修改 + 试用**（2–3 周） | 帧/元素级寻址、圈选、方法库检索注入、10 名创作者试用 | 可用率 + 发出率数据 |

### M1 实现状态（2026-09-23）

已实现并 E2E 验证（9:16 全流程冒烟：新建 → 分镜 → 样张 → 确认 → 制作 50s 竖片 → 段级重做 → 风格提炼入库 → 复用）：

- 三栏工作台（Vue3）：舞台四态 + 制作进度 + 竖屏播放器 + 首页方法库
- Agent 工具链：`save_manuscript` / `draft_storyboard` / `update_storyboard` / `draft_style_samples` / `run_selfcheck` / `start_production` / `rework`（段级重做，修改要求置顶喂给画面 spec）/ `extract_stylepack` / `export`
- 画幅：项目级 `aspect`（**默认 9:16**，可切 16:9），spec 校验/prompt/渲染/组装全链路跟随
- 方法库 v1：`data/library/stylepacks.json`，成片提炼（Agent 起草）→ 用户确认入库 → 新建项目复用
- 风格积木扩充（2026-09-24）：内置 **风格注册表** `ai/registry/styles.json`（13 个风格方向：深空渐变/数学线框/地缘档案/高能说明书/发布会深色/轻快多彩/渐变玻璃/财经图表/公益数据/清洁医疗/自然环保/深色等距科技/黑板粉笔，均带色板 hex/背景画法/字幕条/配图调性），由 **通用 token 引擎** `ai/engines/stylepack_generic.py` 按方向关键词渲染；手绘/扁平两套手写引擎保留。新元素 4 种：`quote`（金句）/`checklist`（对勾清单）/`stat`（指标卡）/`chart_donut`（环形图）。对比度门禁：`colorutil.py` 自动把色块文字/图形拉到 ≥3.5:1。方法库里 13 个风格已播种为可直接选用的样张条目
- 表达力扩展（2026-09-25）：**custom 自由元素**（kind 第 27 个，表达力逃生舱——LLM 直出容器内 html/css/js：css 自动 scope+keyframes 改名防撞，js 走 GSAP 片段（T=揭示秒/ID=容器/tl=时间线，node --check 门禁），每段≤2 个；禁 script/外链/内联事件/position:fixed/CSS transition·animation/repeat·yoyo——校验（contract.validateCustom）→修复轮→Sanitize→渲染侧 _BAN 再拦四道防呆）；**动效词表 v2**：元素级 `anim` 入场覆盖（pop/fade/rise/slide/wipe/blur/chars 逐字仅 title·big/none 直出，组合类 kind 不支持）与 `exit` 退场词位；段级 `camera` 整屏缓推（zoom_in/zoom_out/pan_left/pan_right/drift，内容层 cam 包装，字幕带不动）。全部走 GSAP timeline，seek 确定性（HyperFrames 硬规则 5）
- 素材中心（2026-09-25）：**元素注册表** `ai/registry/elements.json`（27 kind 的 name/category/scene/menu 单一事实源；produce 的 spec 菜单与 kind 清单由它生成，`contract/registry_test.go` 漂移门禁强制与 specKinds 对齐）；**样张矩阵** `ai/element_gallery.py`（每风格 × 每 kind 一张定妆 PNG 到 `data/gallery/<style>/<kind>.png`，ffprobe 总时长均分段取 75% 处，可重入）；API `GET /api/registry|/api/gallery/:style/:file`；前端首页为 **素材中心**（风格库=方法库卡片墙 / 元素库=风格列+元素卡网格，点品牌「帧述」回首页），新建项目的风格选择升级为**样张卡片**（所见即所选）
