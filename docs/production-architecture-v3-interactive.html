分镜后补注章 / 母题 / 节拍表（f1097f2 已建）		退役。节拍表的「预期考卷」职责 → 段审 agent 按 brief+旁白现场推导期望（考卷已退役）；章 → 可砍 / 降可选；母题 → 可选（零母题本就合法）。代价：生成侧失去节拍注入，内容与节拍对应粗一档，记账观察。

组装后 24 帧连环画四查、high 打回 ≤1 轮		拆解。expectation 查 → 段审（对 brief+旁白判卷）；motif 查 → 随母题退役；pacing / deadair 查 → 全片终审（修正②已拍板，本图绿色节点）；衔接查 → 边界审（短片段+末首帧对）。
审核工位：两个档案怎么设计（提示词与 JSON 契约已定稿）
档案触发输入（程序注入）查项（固定，进系统提示词）fix 枚举回合预算
段审 本段渲完 锚点帧（首末帧+句末帧封顶~6）+ brief + 句编号旁白 + 样张 + 设计规则要点 + fact_sheet 条目 六维：内容一致 / 事实 / 风格 / 首末拍合规 / 装置落点 / 字幕文字（每维 pass·fail·NA） redraw / pass ≤6
边界审 两侧段审都过（任一侧重画 → 相邻边界对失效重审） 两侧 brief 承诺 + 边界短片段×2（前后各 1–2s）+ 末帧×首帧对 四查：收尾播完 / 入场起步 / 接续成立 / 突变（闪帧黑帧） stitch_fix / redraw / pass ≤4
全片终审 拼接后 12–16 帧（段界 + 段落界） pacing / deadair / 拼接完整 / 渐变跑偏 按段重渲清单 单轮

判卷型 ReAct：工具只读两件（get_frame / get_clip，ffmpeg+缓存）+ submit_verdict 唯一出口；温度 ≈0；manifest 记每次取证。意见单 findings[] 带「类别+锚点」签名，签名刹车（同签名两轮=停）由程序判定。两份系统提示词全文、JSON 载荷样例、submit 校验清单、边界对状态机见 docs/production-stage-design.md §5.9。

未决 / 记账事项 · AI 的立场

事项状态立场理由
修正③ 刹车降级出口待拍板（剩此项） 建议带伤发布 签名刹车（类别+锚点，同签名两轮=停，停止派发+在飞排干）已设计落地；剩降级出口：倾向带伤发布+manifest 标注——整片作废的钱远超一段瑕疵。
修复轮新发现率记账观察（P4 哨兵） 记账说话 无冻结考卷后「越修越多」的守卫：修复轮先复核既往意见、新发现须 high 才立案；复发则回退「预期先行」（同 agent 盲写预期→再看帧，考卷轻量复活）。
修正① 考卷拆两次调用已消解 考卷退役 考卷退役后，期望源（brief / 旁白）诞生于任何帧存在之前——「写期望时偷看帧」在结构上不存在，修正失去宿主。
审片误报记账提前开张未拍板（建议项） 建议立即开张 夜跑已在产审片数据，成本只是结构化落盘；没有基线，架构前后「更好 / 更坏」不可证伪——未决里杠杆最高。
先配后切（TTS 前移，拿真实句级时间戳再切段）未拍板（建议采纳） 建议采纳 停顿证据 × 话题完整 × 剪辑语法三层合一切段；③的 tts_align 工具已按「采纳后注册」预留，拍板即接通。
装置/皮肤切换与段落节拍配合度记账观察 记账说话 设计系统的内容耦合件（贯穿装置 / skin_rule）在②发明时看不到分镜——量级预期小；段审固定查项含装置落点即是账本；塌了再上逃生舱②′（已预设计）。
渐变跑偏的全片终审捕获率记账观察 记账说话 逐段审的已知盲区（段间渐变单段不可见）交给全片终审兜底；捕获率与按段重渲成本进账本。
时长窗校验（原 8–20s 全局硬带）已了结 每风格段长带 + 全局钳制 段长随风格剪辑语法出（羊皮纸 6–10s / 长镜头 12–18s），全局钳 5–20s（入场动画计入段长）保渲染与审核经济性；优先级：话题完整 > 风格密度。
seam_in 缝型 / 转场库 / 缝处理推导器已退役（v3.1 定稿） 缝概念整体退役 首末拍 = 场景 brief 的内容（③写）；转场 = 设计系统标准入场/收尾模板（②的风格资产）；邻段承诺对所有段白送注入。拼接层永远零改动——「转场分层动 assemble」不是缓做，是不需要。
接缝「治」（参考图修后段）等记账 同意缓做 「防」（邻段承诺 + 设计系统模板）与「查」（边界审对 brief 首末拍）均已并入；治等真伤。
逐缝编辑例外（风格语法 override 表）缓做（等审片数据） 先不做 「跨段就要硬切」这类例外先不做；若审片频繁出现「推导出的开场处理生硬」，再议给③加可选内容级节拍标注。
风格包探索语境对③的价值未证实（观察项） 记账观察 若场景规划反复与风格理由脱节，先做便宜实验：风格描述加「探索纪要」字段跑两批对比。
