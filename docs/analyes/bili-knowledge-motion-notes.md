## 1. 小Lin说「美国贸易逆差为何 Hold 不住」（774 万播）——数据卡片语法

真人书房口播打底（约七成画面），但承载信息的是一套高度纪律化的**图形卡片层**，
全部可用 CSS/SVG 复刻：

- **图表卡**（8:26.2、8:44.0、9:53.8）：白底大卡片占 60–70%，单条折线主线，关键
  拐点钉圆角「标签贴片」（经常账户=红、金融账户=蓝，同色同义全片不换）；讲解者以
  **圆形小窗**压角（直径约 20% 画高），卡片永远是主角。
- **章节卡**（4:22.2 汇率）：黑底满屏 + 金色衬线大字「汇 率」+ 英文小字 FOREIGN
  EXCHANGE + 货币符号方格边框，静置约 3s，是全片的"章回标题"。
- **概念卡组**（9:01.4–9:36.3 国际收支）：深底横排三张同构卡（经常/资本/金融账户，
  各配图标），讲到哪张点亮哪张，其余压暗——卡组本身就是叙事进度条。
- **数字特写**：结论性数字单独满屏一瞬，前后有铺垫镜头，让数字"砸"出来。
- 字幕：底部居中白字，常驻同位，从不换位。

## 2. 队友去质器「垃圾场上的妙妙屋·日本世博会」（453 万播）——巨字标点+假UI证据

封面与片头是黑底大字+扁平吉祥物（纯图形语言）；正文为新闻素材混剪，但三件排版
纪律极硬：

- **数字巨字卡**（0:24.5）：黑底满屏特大白字「90–250公斤」，数字+单位一行，无其他
  元素，静置约 2s 当"标点"，全片 ≤3 张。
- **假 UI 证据贴片**（0:48.5、1:24.5、1:30.5）：CSS 可复刻的界面证据——视频站页面
  截图框、新闻台标横幅（橙色「物贖NEWS」贴片），配红圈/箭头标注，占画面 ≤60%，
  斜切防呆板。
- **大字幕纪律**：底部居中超大白字黑描边（≤15 字/行），全片常驻同位；素材给字幕
  让出下 1/5。
- 节奏：混剪段 0.38 切/s（1.5–2.5s/镜），密段之间用巨字卡/黑场当疏段呼吸。

## 3. 珑师傅「秦汉纹样·中国纹样发展史 7」（302 万播）——章节巡礼长镜

知识区长镜头极端案例：231s 只有 4 个切点，全片一张宣纸纹理底，节奏完全靠镜头内
运动与章节锚点推进：

- **一张底焊全片**：米白宣纸底 + 低透明纹样水印，文物照片/插画/图卡被同一纹理焊成
  一体，全程不换底色。
- **章节大字锚点**：每章顶部压黑体大字（「云气纹」36.5s 起 /「四神纹」138.5s /
  「博局纹」154.5s /「车马纹」230.5s），风格一致只换内容，观众靠它定位进度。
- **满幅巡礼图**：章内 15–25s 一景的器物/画作特写，缓慢 pan/zoom/渐显；底部一行
  白字注解 + 来源小字（馆藏/出处）。
- **朱红点缀 ≤2/章**：红色印章卡（6.5s 战国漆器凤鸟纹）、红字梗（218.5s Lagrangian），
  用在最想被记住的一句上，其余点缀色让位给底色与主体。
- 对我们的意义：img/photo 层 + 纸纹 fx + 章节大字即可复刻；注册表「暖砂人文纪事」
  已捕获其色彩气质（字体解析成了雅黑，复用时建议手修为楷体栈）。

## 跨片共性（三片全遵守，与第一批 MAD 四片互补）

1. 字幕锚位全片固定；知识区多一条：**出处意识**（来源小字/馆藏标注/引文贴片）。
2. 章节锚点承担导航（章节卡/章节大字），长片没有它必散。
3. 底色/纹理全片统一（宣纸米白/书房暖灰/黑幕），异质素材靠它焊住。
4. 关键数字单独成镜，绝不埋在连续语流里。
5. 图形层与素材层分工明确：卡片/贴片承载信息，照片/混剪承载情绪，互不抢戏。
