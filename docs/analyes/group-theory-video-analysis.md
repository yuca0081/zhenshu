# 群论之美 · 案例解析与引擎升级路线

> 状态：v1（2026-09-27）。样本：B 站 UP 主 sadsxa 的「群论之美」（B 站 DASH 流，
> AV1 1080p30 / AAC 44.1kHz，262.6s，本地样本 `42199355184-1-100026.m4s` + `-30232.m4s`）。
> 结论来源：26 张全片总览帧 + 3 个 10s 窗口 2fps 密集帧 + 音频频谱；
> 平台侧限制逐文件盘点（`server/internal/contract/spec.go`、`ai/render_spec.py`、
> `ai/engines/stylepack*.py`、`server/internal/produce/frameqa.go` 等，下文均带路径:行号）。
> 姊妹篇：`docs/analyes/ink-fluid-analysis.md`（水墨案例，结论不同）；上位文档 `docs/plan.md`。

## 1. TL;DR

**这不是渲染技术代差，是"表达词汇表 + 审查闸门"的差距。** 对方同样是网页渲染路线
（用户确认 LLM 制作；画面特征与无头浏览器 + 程序化绘制完全吻合），咱们引擎底层
（无头 Chrome + GSAP 暂停时间线 seek 截帧 + ffmpeg）能做同样的事，但 spec 契约里
**没有给模型表达这类画面的词汇**，而四道质量闸门在主动把画面往"合格信息卡片"收敛。
修法不是换引擎，是立法：加 **scene/canvas 确定性逐帧通道**（P0，一个改动打开 80% 差距）、
公式/双语字幕/章节/转场/镜头关键帧（P1）、质感 fx 与闸门分级（P2）。

与水墨案例的关键区别：点睛的流体模拟是**有状态**的（第 N 帧依赖全部历史），
装不进 seek 截图模型，只能走"离线渲染 mp4 入库"；群论之美的大量画面是**无状态
纯函数绘制**（`t → 画面`，弦图生长/粒子/线框 3D 都是），恰好装得进咱们的
seek 确定性模型——只缺一条通道。

## 2. 样本拆解

全片 ~4m22s，一章一个视觉主题，无一帧"PPT 卡片"。按时间轴：

**全片统一的设计系统**（这是"高级感"的直接来源）：深空黑底 + 金/青霓虹辉光 +
宋体系衬线中文 + 底部双语字幕（中文主行 + 英文斜体衬线次行）+ 左上罗马数字章节角标
（VII 群与对称 / VIII 椭圆曲线 / XII 错误校正码…）+ 场景叠化转场（密集帧可见字幕叠影）。

**音频**：频谱显示全程 BGM 铺底（低频连续能量 + 和声层）+ 人声；响度 -16.5dB mean /
-0.8dB peak，商业级母带。

## 3. 咱们平台的精确限制（逐条对照，路径:行号）

### 3.1 渲染链路（不是瓶颈）

- `npx hyperframes@0.8.55 render` 按段渲染（`pipeline.go:473-474`），增量重渲
  （`segStale` `pipeline.go:494-509`），concat 免转码拼 `main_voice.mp4`（`pipeline.go:513`）。
- 1920×1080 / 30fps（`contract/constants.go:8-12` SegTail=0.35、FPS=30；
  `ai/assemble.py:26`）。与样本同规格。
- JS 驱动 = GSAP 暂停时间线 + seek 截图（`assemble.py:66-73`、`stylepack.py:117-125`）；
  确定性靠禁令：rAF/setTimeout/setInterval/Date/Math.random/window/document/repeat/yoyo
  全禁（`spec.go:826-836`、`render_spec.py:861-864`）。

### 3.2 spec 契约（词汇表瓶颈）

- 26 种元素 kind（`spec.go:96-106`），每段 3–12 个（`spec.go:355`，prompt 收紧 4–7）。
- custom 每段 ≤3 个（`spec.go:635-637`），html ≤3200 / css ≤2000 / js ≤2000 字、
  w 80–1800 / h 60–1000（`spec.go:853-863`）。一个心形线场景就是 200–400 行代码，
  预算差一个量级。
- 动画：入场 8 词 pop/fade/rise/slide/wipe/blur/chars/none（`spec.go:413-417`）；
  退场唯一 exit_fade（`stylepack.py:181-183`）；镜头 5 词且全是微动——zoom 1↔1.05、
  pan ±36px、drift scale1.035（`spec.go:358-362`、`render_spec.py:170-176`）。
- **无 canvas/WebGL 通道**：custom 的 js 只能是 GSAP 片段（约定 T/ID/tl，
  `spec.go:83-84`、`render_spec.py:936-943`），禁 DOM 查询（`spec.go:830-834`），
  CSS animation/transition 在禁区（`spec.go:821-825`）。
- **无公式通道**：无 KaTeX/MathJax，公式只能当普通文本（quote ≤22 字，`spec.go:434-435`）。
- 重叠 >25% 违规（`spec.go:659-662`）、字幕带 y≥CapTop 禁放（`spec.go:33,45`）、
  越界/文案超长回喂修复，再不过 SanitizeSpec 确定性降级（`spec.go:691-804`）。

### 3.3 风格系统（审美瓶颈）

- 13 内置风格 + 1 参考片提炼条目（`data/library/registry/styles.json`）；tokens 有
  bg/ink/accent[6]/radius/cap/img 等（`stylepack_generic.py:48-83`）。
- 背景 fx 仅 5 种静态：glow/stars(34 个 LCG 星点)/dots/grid/grid_persp
  （`stylepack_generic.py:120-179`）。无粒子/噪点/暗角/景深；vid-ref 条目声明的
  `noise` fx **无实现**，静默忽略。
- 辉光只是静态 radial-gradient 光斑；文字辉光不在词汇表。
- 背景图被强制叠纸色 scrim（a_top=0.28+0.38·dim，`render_spec.py:337-363`），
  照片影调被洗平。

### 3.4 审查闸门（反向作用瓶颈）

- 四道闸：ValidateSpec → hyperframes check（回喂 ≤3 轮，`produce.go:403-469`）→
  frameQA 四帧视觉审查（0/0.8s/段尾-0.3s/尾帧-0.08s，`frameqa.go:32-37`；**空白>25% 标红**
  `frameqa.go:411-430`）→ 风格闸（皮肤对比度 ≥3:1，`types.go:133-135`）。
- 对比度自动纠正把深底文字一律改成 #EFE9DA/#E3E3E3 级、中灰 #616161/#9E9E9E 禁用
  （`produce.go:442-448`，建议色回填 `applyContrastFixes` `produce.go:1194-1245`）
  ——微妙的暗调层次被"纠正"掉。
- 这套闸门对"信息卡片"是对的；对"一朵雪花居中 + 大片深空"的电影构图是系统性误伤。

### 3.5 字幕 / 章节 / 音频 / 素材

- 字幕带：管线自动生成、**单语中文**（取旁白原文 `tts_align.py:16-25`，短语胶囊 +
  词级逐字高亮 `stylepack.py:93-107`）。无双语/翻译机制，LLM 不可控；无章节角标层。
- 转场：**段间硬切**（`assemble.py:69` 注释"转场为独立验证项"，v1 未做）。
- 音频：TTS 级联 SiliconFlow→Edge(晓晓)→Kokoro（`tts_align.py:291-303`）；
  BGM 仅 3 首程序化合成 pad（`make_bgm.py:136-158`），stitch 侧链闪避混音
  （`pipeline.go:651-683`）；无 sfx 机制。
- 素材：catalog 68 条（3 BGM + 65 图）；生图 CogView 免费档带水印
  （`fetch_images.py:19-22`）。

### 3.6 七类表现力判定

| 表现力 | 判定 |
|---|---|
| 程序化数学艺术 | **缺失**（无 canvas 通道，纯函数绘制其实兼容 seek 模型） |
| 3D | **缺失**（仅 CSS perspective 网格） |
| 粒子 | **缺失**（仅 34 静态星点；动态粒子无通道） |
| 数学公式排版 | **缺失**（无 KaTeX，字数上限卡死） |
| 双语字幕 / 章节角标 | **缺失**（单语自动字幕；无章节层） |
| 辉光 / 转场 / 运镜 | **受限**（静态光斑；硬切；5 个微动预设） |
| 风格化信息图 | **充裕**（26 元素 × 13 风格 × 版式库 + 四道闸）——恰好是参考片里没有的那一档 |

## 4. 归因：为什么做不出

1. **词汇表**（主因）：canvas/公式/双语/章节/转场在契约里不存在，LLM 想得到也写不出来。
2. **预算**：custom 3200 字 vs 场景代码 200-400 行，量级差 10×。
3. **闸门反向收敛**：对比度纠正、空白>25%、重叠>25% 都按卡片逻辑立法，把电影构图当缺陷修。
4. **审美主导权**：参考片是贯穿全片的一套艺术指导（统一字体/色/动效节奏/章节系统）；
   咱们是 13 个皮肤让 LLM 摆卡片，气质天然是"讲解卡"。
5. **不是瓶颈的**：渲染器（同代技术）、分辨率帧率、词级对齐时钟（tts_align 反而是咱们的
   强项，参考片的逐词字幕咱们已有同款机制——只是单语）。

## 5. 落地方案

### P0：scene 通道（一个改动打开 80% 的差距）

1. **新增 `kind=scene`**：全画幅 canvas 元素，画满安全区但豁免重叠/空白/元素数检查。
   确定性约定 `window.__draw(t, ctx)` 纯函数（同 t 同像素）；随机性用内建 seeded PRNG
   （如 `mulberry32`，注入 `window.__rng(seed)`），继续禁 `Math.random`/Date/rAF。
2. **驱动零改动**：scene 注册一个 GSAP 占位 tween（与现有元素同机制），在
   `onUpdate` 里取 `tl.time()` 调 `__draw` —— seek 时间线时 onUpdate 必触发，
   hyperframes 侧不用动。
3. **预算放开**：scene 不受 3200/2000 限制，给段级代码预算 ~20k 字；保留
   `node --check` + 新增**确定性回放测试**（同段渲 t=0/中/尾两次，像素 diff 必须为 0）。
4. **审查适配**：frameQA 对 scene 段只查黑屏/裂图/提前穿帮，跳过重叠/空白/重心检查；
   对比度闸门对"深底+发光前景"豁免中灰禁令（标题/辉光元素按亮度分级，不再一律米白）。
5. 打开的能力：粒子系统、3D 线框/点阵投影（手写 3D→2D 投影 ~50 行）、生成艺术、
   加色混合辉光（`globalCompositeOperation='lighter'`）、函数曲线绘制。
   先例：`demo/ak-pv-repro/build_ak.py` 手写引擎绕开 spec 词汇直产 comp JSON
   （雪花/余烬/冲击变焦全做出来了）——P0 等于把那条旁路转正。

### P1：统一观感的三件事

6. **KaTeX 离线打包**进渲染容器（禁 CDN），新增 `kind=formula`（tex 字符串 +
   字号/颜色/位置），浏览器端确定性排版。
7. **双语字幕 + 章节角标做成管线层**：字幕带已有词级时间戳，补一行机器翻译英文
   （衬线斜体次行，主行下方），project 级配置开关；章节角标做 project 级统一 track
   （数据 storyboard 里已有，罗马数字 + 章节名渲染在固定位置），LLM 不再每段手摆 chip。
8. **段间转场**：assemble 全局时间线预留位已存在（`assemble.py:69`），加叠化/闪白
   （相邻段尾首 opacity tween 0.4s）即可，seek 确定性不受影响；可选 whoosh sfx。

### P2：质感与审美

9. camera 关键帧化：起止 zoom/pan/rotate 可配 + easing 可选，替代 5 个微动预设。
10. 背景 fx 扩充：noise / vignette / particles（沿用 stars 的 LCG 确定性先例）；
    取消背景图强制纸色 scrim，改风格 token 决定；text-shadow 辉光进 token。
11. 把本参考片走现成 `extract_stylepack` 提炼成内置风格「暗空霓虹」（深空黑金青 +
    衬线 + 章节 + 双语字幕模板），方法库注入 spec 生成。
12. 音频：TTS 升付费 CosyVoice 档；BGM 曲库扩充按章节情绪选曲；转场 sfx 层
    （riser/whoosh，stitch 混音已有侧链闪避基建）。

### 明确不做

- 不换渲染引擎（hyperframes/GSAP 路线已验证，瓶颈不在这）；
- 不让 LLM 自由写有状态模拟（有状态物理走水墨篇的"离线 mp4 入库"路线，
  两篇方案互补不冲突）；
- 不接视频生成 API（同水墨篇结论：不可控）。

## 6. 风险与待定

- **LLM 写 20k 字 canvas 代码的可靠性**：靠方法库注入场景代码模板（弦图/粒子/线框
  各给一份参考实现）+ `node --check` + 确定性回放测试三道兜底；写砸降级为静态帧。
- **性能**：全画幅 canvas 逐帧 JS 绘制，30fps × 长段的截图耗时上升；先按段实测，
  慢的段用"关键帧预渲染 + 补间"降频绘制。
- **闸门放宽的回归风险**：scene 豁免只对 `kind=scene` 生效，卡片元素四道闸维持原样，
  避免现有质量回退。
- **版权**：参考片画面不可搬运，风格提炼只取设计语言（色/字体/构图语法），
  场景代码全部自写。

## 7. 验收路径

1. **原型闸**：单段 scene 复刻"乘法表弦图 ×2→×3 生长"，`__draw(t)` 确定性回放
   diff=0，肉眼对比样本片段；同时验证 20k 预算 + 审查豁免链路。
2. **链路闸**：出一条 60s 测试片，齐活 scene + formula + 双语字幕 + 章节角标 +
   叠化转场 + camera 关键帧，全管线跑通。
3. **进阶闸**：真实选题（数学/科普类）走完 文稿→分镜→样张→成片，对比现有管线
   成片做盲评。
