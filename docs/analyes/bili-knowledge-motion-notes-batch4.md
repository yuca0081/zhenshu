## 1. 江城kaya「数学之海」（101 万播）——暗黑图鉴流

克系暗黑美学+手绘墨稿：做旧宣纸底上水墨笔触画"数学怪物"，词条式标题
（「拉普拉斯妖」「混沌学」「帕斯卡赌场教堂」），标注气泡写注释；词条页之间插
近黑满幅意象页（深海/雾山/极光，只压一句白字）当换气口；正红只用于致命信息
（希帕索斯之死红三角）；标题全片楷体/衬线。开场黑场+公式雨定调。

## 2. 中气爱「冰鲜的南方人，你们比北方更冷」（45 万播）——数据图层流

气象数据可视化：全国气温色斑图满幅（绿黄热力+20~40 个「地名+数值」标注网格）、
500hPa 等压面图（等值线+色阶）、日期锚点「2026年3月31日」常驻右上角、白底温度
走势小卡、实拍空镜（雾/花/油菜花）3-5s 做呼吸；白字黑边底部字幕+频道 logo 常驻。
数据图本身当背景，结论直接标注在图上，不做单独图表页。

## 3. 小聪明张建国「你经常做的事，有可能要了你的命？」（520 万播）——清单快科普流

60 秒讲 3 个危险点：每条用编号句开场（「1.如果你家洗碗的钢丝球缠在一起」「2.如果
你久坐腿麻」），每条换一个高饱和纯色底（橙/蓝/黄/深蓝），简化人形/局部特写做
图解，关键词条正红大字跳出（「99%」「要摸着黑」「十几二十块」），白底黑字结论条
收束。0.38 切/s 高密度但每条要点内部结构固定：场景→特写→结论。

## 4. 燎结构「有意思的桥墩」（111 万播）——工程图解流

单一深青底 + 3D 构件双色高亮（黄=盖梁、红=主墩，其余灰白），全片 4 个切点、
中位镜长 47.9s——长镜环绕+构件渐次出现讲力学机制；字幕条点题（「节点就会左右
滑动」）；彩色截面标注条（紫黄绿红蓝竖条）对比标准化优劣；提问贴纸（「你会怎么
设计」紫底圆角）开场互动。3D 环绕不可复刻，但「单底色+焦点构件上色+其余灰化」
完全可用 wireframe/SVG scene 复现。

## 5. 大瑞真机灵「驾照竟然还有这么多隐藏用法！」（110 万播）——UI 流程流

办事教程模板：Q 版主持人（全片同一形象固定锚位）+ 灰白线稿场景插画（车管所/
体检机/柜台）+ **真实 UI 的插画级复刻**（交管12123 列表页、业务选项卡），红框+
放大标注当前步骤按钮（「电子行驶证」「遗失补证」），步骤编号大字（「2 到期想换
证」），红字关键词（NEW/这些精彩）点缀；开场 5s 先给最终效果再讲步骤；结尾假
推荐流贴片导流。

## 跨片共性（五片全遵守）

1. **一屏一个焦点**：图鉴页只有一个词条、数据图只讲一个结论、清单条只红一处、
   工程图只上色一个构件、UI 只框一个按钮。
2. **锚点常驻**：日期（中气爱）/编号（张建国/大瑞）/词条标题（kaya）/字幕条
   （燎结构）——观众随时知道自己讲到哪。
3. **呼吸位**：密标注段之间必有疏段（意象页/空镜/主持人半身镜/黑场）。
4. **正红 = 警报语义**：五片都把红色留给"最该记住的那一处"，不做装饰色。
5. 短打结构：60-90s 的片子开场 3-5s 必抛钩子（反常识/提问/终点前置）。
