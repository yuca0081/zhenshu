## 1. 内容与结构

斗拱科普:以梁思成《图像中国建筑史》为底本讲"斗拱是什么、怎么演变、为什么能用来断代"。叙事弧完整度是四条片子中最高的:

- **开场钩子(0~26s, uni_01~02)**: 不讲定义,先给悬念——"屋檐从柱子中线往外挑出三米七"。画面为佛光寺东大殿剖面线稿,标注"上檐出3.74米",随后缓推(zoom-in)到斗拱局部,给出"椽1.76米/斗拱1.97米"的分解尺寸。每个数字都带小字来源(实测数据论文、《营造法式》)。
- **立论(26~61s, uni_03~06)**: 唐(佛光寺)vs 清(文渊阁)同比例双柱对比,推翻"斗拱只是装饰";3D 轴测爆炸图标注"拱/华拱、斗/栌斗"(uni_05);红色力流箭头从檐顶一级级传回柱底(uni_06),用动画讲受力路径。
- **展开·历史线(61~96s, uni_07~10)**: 顶部朝代时间轴从秦汉→唐→宋辽金推进,汉石阙佐证、"唐代遗构更不用幻想"的悬念页(uni_08)、宋《营造法式》材分制("房子的尺子", uni_10)。
- **侦探高潮(96~113s, uni_11~12)**: 宋下昂(斜置杠杆)vs 清假昂(平置装饰)对比;1937 年梁底墨书"佛殿主上都送供女弟子宁公遇"与殿前经幢刻文"一对——"互证断代。这是全片戏剧性最强的一页。
- **数据高潮(113~122s, uni_13)**: "十一座建筑,同一把比例尺"——唐857/辽984/宋1125/元1250/明1421/清1776 六柱并列 + 下方散点图量化"斗拱高÷柱高"从 1/2 跌到 1/5。注释写明"六组剖面由本片**参数化生成器**按各代用材绘制"。
- **升华收尾(122~139s, uni_14~16)**: 梁思成引文"古之斗栱本为结构中主"→"THE CHINESE 'ORDER'"中西柱式对比→末帧 1/2 vs 1/5 大字分数+"看斗拱就能大致猜出它的年纪"。

结构评价: 这是把一篇学术资料重构为"钩子→机制→通史→侦探→量化→格言"的标准爆款知识结构,信息主线(断代尺)贯穿始终,收尾呼应开头(尺寸→比例)。

## 2. 视觉工艺

- **美学统一**: 米黄羊皮纸底 + 深红强调色 + 建筑制图线稿(斜剖面 hatch 填充)+ 衬线宋体标题 + 罗马数字/年份,全程零跳戏。配纸纹质感与四角画框装饰线。
- **导航组件**: 顶部朝代时间轴是贯穿全片的"进度条",随叙事高亮当前朝代并显示年份(857/1103/1734/1932/1937),观众始终知道自己在历史哪个位置——这是典型的"状态驱动 UI",确定性渲染管线的强项。
- **信息密度**: 中高且克制。每个学术画面底部都有两行小字来源注释(《营造法式》卷四、1944 论文、Encyclopedia Americana),可信度远超普通科普。竖屏构图上下留白大、主体居中。
- **动效水平(帧序列推断)**: 属"信息图动画"流派——镜头缓推(uni_01→02 同场景连续推近)、标注线/箭头生长、轴测爆炸分层、力流逐级下传、字幕整句渐显(uni_09 抓到半透明渐显中间态)、六柱逐个生长(uni_13/14 同构图的增量变化)。无角色动画、无场景间花哨转场,靠"每句旁白对应一个画面状态变化"维持节奏。
- **字体/排版**: 标题衬线+正文黑体+注释小字灰阶分明;竖排文字卡(uni_12 经幢刻文)处理得当;比例尺、图例齐全,接近出版物水准。

## 3. 水平定位

**8 / 10**。(a) 对标专业 MG 工作室: 7~8 档——版式、史实严谨性、结构俱佳,但动效以缩放/渐显/生长为主,没有复杂角色动画或三维运镜,属于"高级信息图"而非"炫技 MG"。(b) 对标 B 站头部知识区 UP(回形针/柴知道级): 达到其纸面水准、学术密度更高(回形针少有如此密的引注),但缺少音效设计与其成名段的节奏密度。

扣分项: 动效幅度小、竖屏若干段落偏空、个别转场瑕疵(见 §5)。加分项: 参数化生成器产出的六朝斗拱剖面是全片最硬的资产,普通 UP 无法在合理工时内手绘完成。

## 4. 与"文章→自动成片平台"的差距拆解

**模板+组件可复刻(估约 60% 的画面)**:
- 顶部朝代时间轴导航(状态驱动,spec 里就是"当前朝代+年份"两个字段)
- 纸纹底、四角框、标题/副标/来源注释三层排版、竖排文字卡
- 双栏对比布局(唐vs清、宋vs清)、比例尺组件、图例
- 散点图(uni_13 下半)、大字分数页(uni_16)、引文引用块(uni_14)
- 字幕系统、淡入/缓推/生长这三类基础动效、标注引线组件

**必须模型自由创作(差距所在)**:
1. **核心图形资产——斗拱剖面/轴测图**: 六个朝代、同比例、形制各异的建筑制图,模板库里不存在"唐斗拱"这种组件。片尾注释自曝解法: Opus 写了一个"参数化生成器"按各代用材绘制——即 LLM 现场编写领域图形代码。这是平台当前管线没有的环节("模型生成参数化图形插件"),也证明该路线可行。
2. **知识重构与内容策划**: 从一本书提炼出"斗拱高÷柱高 1/2→1/5"这条可量化主线 + 梁思成寻唐构的侦探叙事,是选题/编剧能力,不是渲染问题;平台若只有"文章摘要→分镜"能力,产出的是要点罗列而非叙事弧。
3. **镜头的语义理解**: 对剖面"哪里值得推近"(斗拱局部而非全殿)、力流路径的起止,需要理解图形几何含义才能编排。
4. **配音**: Gemini TTS 产出旁白;平台的 TTS 环节可对标,不构成差距。

**结论**: 差距主要卡在"定制图形资产生产"一环。版式与图表层平台能追平;把"LLM 写参数化图形生成器"纳入管线(生成→注册为组件→spec 引用)即可覆盖此类视频的主体。

- **uni_08(≈70s)**: 低信息密度段——整屏仅"唐代遗(构)"两字+一行灰字,竖屏 70% 留白;且大标题呈打字/渐显中间态,"唐代遗"疑似截断观感。
- **uni_09(≈79s)**: 字幕以半透明渐显状态被抽中,可读性差;该帧同时是"单柱居左、右侧全空"的失衡构图。
- **uni_05(≈44s)**: "拱"字标注与引线、构件线条轻微压叠;"华拱"小字紧贴 hatch 填充区。
- **uni_02(≈17s)**: 底部两行来源注释字号过小,在竖屏手机端接近不可读。
- **uni_13(≈113s)**: 散点图 X 轴仅标 900/1100/1300/1500/1700,无轴题;柱状图与散点图两套信息同屏,首次观看需字幕扶着走。
- 整体无锯齿、无糊帧、无错别字(抽查"栱/拱"混用属学术惯例,不计)。"AI 味"低——风格来自《图像中国建筑史》原书图纸,而非 AI 默认审美。
