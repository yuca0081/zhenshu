## 2. 视觉工艺

- **版式**:单骨架三栏(顶栏歌名+章节+运行钟;左聊天;中可视化;右 ops 轨;底 stdout·tokens 歌词栏;最底 credit 跑马灯),212 秒不换骨架,只换面板内容与配色状态。顶栏运行钟与真实片长同步(00:00.5/03:32 → 03:32),细节控。
- **配色剧作**:蓝(正常)→红(崩溃/处决)→粉(恋爱)→黄(奖励 hack WARN)→蓝灰(谢幕),颜色本身承担叙事,这是真正的"状态驱动美术指导"。
- **招牌装置**:底栏把每句歌词拆成 token 色块并标注 token 数(uni_01 的 "And let's begin object" 下方 36621/28551/74995/54921),逐句复用,是全片最有辨识度的歌词渲染系统。
- **可视化面板**:loss 曲线、8 卡功耗、注意力/传输点阵、采样分布、GRPO 打分卡、概率表,全是 ML 真实语义,不是随机科技图形。4K 下所有正文可读(960px 抽帧仍清晰,可读性优于 BV1SgaY64EG5)。
- **动效推断**:全片仅 1 处场景分超阈值(146.25s 章节卡),即无镜头语言、无转场设计,动效=打字机/滚动/曲线绘制/毛刺闪断。对 TUI 题材这是正确选择,但 3 分半不动机位,中段(0:53–2:12)的观看节奏明显塌腰,靠弹幕和字幕撑。
