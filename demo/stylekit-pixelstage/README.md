## 配方笔记（≤14 行）

1. 双分辨率合成是本风格的地基：像素层 320x180 逻辑画布 2x 最近邻放大，辉光/烟雾/渐变画全分辨率平滑层，两层分开再叠。
2. **底色必须画在像素层**——平滑层放不透明底会把像素层整个盖掉（r1 判卷烧掉 B/C 两格的教训）。
3. 色彩三律：黑白灰单色舞台；橙 #F08030=可交互层；电光黄 #FFFF00=生命/焦点，全场至多两处。
4. RGB 撕裂按部件给不同错位量（躯干轻、手臂重），用 multiply 通道掩膜 + lighter 合成。
5. 手持机位感：每个 UI 元素独立 2°-8° 微旋转，不是刚体。
6. 纸屑 = 4-10px 多色像素团（红蓝为主黑白夹杂）+ 从爆点向外的密度梯度（t=rr()*rr()）。
7. 高光/烟是**块状像素团**不是 bokeh 光斑（r2 判卷教训）。
8. 爆点三层：RGB 错位描边小屏框 + 像素黄爆发核（长在屏上）+ 单个弱辉光。
9. 台缘是连续红灯带；下方才放断续故障扫描行（深蓝/青绿/砖红）。
10. **无 CRT 滤镜**：禁扫描线/网纹/弯曲——这是「像素+现代辉光」，四帧逐行亮度平坦的证据。
11. letterbox 用前先像素实测真迹边带（frame-02 满幅白被首读误判成黑边，判卷官又反判——用 PIL 量了才裁决）。
12. 已知弱点：换题图上 RGB 撕裂/扫描行存在感低、形状被暗场吞（终审判语）；B 手臂噪点密度仍逊真迹；C 爆核缺线框轮廓。
13. 黑帧（#101010）与径向白闪（带 5% 余像）是段落开关，本包未做动画版。
14. 全部随机走种子（mulberry32），同种子逐字节复现（已验证 out-c 重渲 MD5 一致）。
15. 【三方对比复审】RGB 色散不可下放为元素填色——真迹的撕裂是爆点专属特效；主体一律白色单线稿，色散只允许出现在打击/爆炸点及其飞散物上。
16. 【三方对比复审】UI 墨水层取色锁真迹值域（黑/白/黄/橙），青/品红/粉禁用（CAM/RATING 曾误用青色）；橙色描边按钮排（战斗/行动/物品）是必复刻的签名件。

### 附录：手册臂对照实验（2026-10-26，消费形态之争）

争议：画面工位该「调用冻结 kit+小抄」还是「给全码手册让模型仿写」（成册不封装）。
做法：隔离写手 agent 只给手册（kit.js 全源+小抄+配方笔记+考题A范例，**禁读考题答案、禁 import kit**），
仿写 C/N 两命题（自包含单文件 manual.html），一轮看图返工后与 kit 终审样张同图盲评（同一判卷官）：

| 命题 | kit 终审样张 | 手册仿写臂 | 判卷官关键语 |
|---|---|---|---|
| C 暗场爆炸舞台 | 28/40 | **32/40** | 手册臂舞台镜头感最强、撕裂限爆点全中；kit 臂纸屑偏碎+两处平滑光斑偏离硬像素 |
| N 换题中性图 | 86/100 | 84/100 | 平手（判卷噪声内）；kit 臂红带跑画面中部，手册臂方块少微旋转 |

结论：**单幅风格质量仿写不输封装**（C 胜 4 分、N 平）；真差异在成本与结构保证——
手册臂实测 ~20 万 subagent token/命题（读 30KB 手册+全码重写），kit 臂生产形态只需 2k 小抄+短场景码；
跨段一致性/坑免疫/毕业七查这些冻品优势单发实验测不出。落点待拍板：小抄升格（内嵌核心代码段）
或手册成册为主、kit 冻结为可选层。复现：`manual-arm/manual.html`（?scene=c|n&seed=1，MD5 逐字节一致已验）、
`manual-arm/judge-blind.png`（盲评拼图，X/Y 映射见 server/tmp/manual-arm/sheet3.py）。

② **判卷官方差大于一切臂间差异**——同一张 kit 终审样张三个判卷官实例给出 31/28/23（C）和 82/86/68（N），
±8-18 分的噪声淹没臂间 1-7 分的差距。**第 2 步自动化判卷不能依赖单判卷官调用**：须多判卷官取中位

成本侧修正：迷你臂 29.9 万/2 命题（1 轮）、手册臂 40.6 万/2 命题（2 轮）——场景写作本身主导开销，
册子大小（2.8K vs 9.5K vs 30K）的边际差异被淹没，真正的成本杠杆是返工轮数。

## 重渲（种子确定性）

```bash
W=$(cygpath -m "$PWD")  # Windows 风格路径（Chrome 不认 /d/ 开头）
CHROME="/c/Program Files/Google/Chrome/Application/chrome.exe"
for s in a b c n; do
  "$CHROME" --headless --use-angle=swiftshader --enable-unsafe-swiftshader \
    --hide-scrollbars --window-size=640,360 --virtual-time-budget=30000 \
    --screenshot="$W/out-$s.png" "file://$W/style.html?scene=$s&seed=1"
done
```

改 seed 参数可换确定性变体。对照真迹在 `data/references/ref20261026-103650/frame-01|02|03.png`。
`judge-*.png` 是判卷拼图（上排真迹下排还原），`bare.html`+`out-bare.png` 是三方对照的形容词版，`tri-compare.png` 是三方对比终图（KIT 82 vs BARE 56，验收立住）。
