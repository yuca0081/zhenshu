# zhenshu-kit 规则书（房内版）

> 画材包统一契约的房间墙贴：docs/zhenshu-kit-spec-2026-10-26.md 的执行摘要。
> 与监工提示词同源；冲突时以本文件为准（它钉死在地基镜像里，随版本可追溯）。

## 1. 三层结构（谁负责什么）

```
场景代码（scene-exam-*.html / scene-neutral.html，你写）——画什么：构图/内容/文字
zhenshu-kit（kit.js + 配角文件，你写）            ——怎么画：画风原语+纪律+后处理
底层画图库（p5.brush / p5 / 纯 Canvas2D，你选型）  ——被 kit 封装，场景代码永不见库
```

- 选型自由，但选型理由写进 kit.json 的 framework（选型本身是风格知识）。
- 零依赖合法（纯 Canvas2D 完全够像素族这类画风），此时 deps 留空。

## 2. 统一 API：四类语义原语（CheatSheet 必须按这四类组织）

| 类 | 语义 | 像素族实例 | 笔刷族实例 |
|---|---|---|---|
| 笔 mark | 落一笔/一块的原子与部件组装 | rect/text/box/part+stamp/rgbSplit | brush.line/spline/wash/flowField |
| 色 palette | 取色纪律的唯一入口 | 调色板对象（焦点色≤2处） | 色阶/明度场查 10 档 |
| 纹理 texture | 颗粒/纸纹/做旧/扫描行 | scanRows/pixSmoke/confetti | grain/做旧三层/颗粒暗角 |
| 明度 light | 分层/光/辉光/色阶控制 | 双画布分层/glowSpot | 图层混合/toneWash |

跨族硬性要求：

1. **种子确定性**：一切随机走种子，构造传 seed，禁 Math.random；同 seed 同场景
   渲染逐字节一致（监工会重渲两遍对 MD5，不一致=毕业检查⑤不过）。
2. **分层契约**：kit 声明自己的层模型，「底色画在哪层」写进 CheatSheet 首条
   （前车之鉴：平滑层不透明底盖掉整个像素层）。
3. **compose 收口**：后处理链（辉光/色差/噪点/做旧）只经 kit 的 compose 一次
   收口，场景代码不自行叠加后处理。
4. **转场件**：黑帧/白闪/段落开关由 kit 提供。

## 3. 库坑封装（已知坑，必须在 kit 层挡掉）

- p5.brush 2.2.3：`brush.add()` 的 pressure 隐性必填；流场用完必须 `noField()`；
  **两点 `spline()` 静默不渲染**（两点笔触走 `brush.line`）；`wash()` 前必须
  `noStroke()`；`'ink'` 不是内置笔（用 pen/rotring/2B/cpencil 等）。
- Canvas2D 分层：不透明底的覆盖顺序（底色永远画在自己层的最底下）。
- 新发现的坑：封装进 kit + 记进 kit.json 的 notes，不得留给场景层。

## 4. 去题材化纪律

- kit 永不包含题材内容：人物造型、图标、文字内容、叙事元素一律属场景代码。
- 例外：**画风签名件**（换一个故事还用的东西，如战斗UI的橙框按钮排、LIVE 角标）
  属于画风语言，可进 kit；边界判据=「换一个故事还用不用」。
- 毕业必测换题考试：`scene-neutral.html`（圆+方块+波浪）必须保持画风——描红
  （只会抄考题构图）在这里露馅。

## 5. 判卷口径（你的作品怎么被打分）

- 四维各 10 分：像素感/块感锐度 · 色阶值域与色板命中 · 质感分层与特效形态 ·
  构图语言。盯风格特征，不逐像素比对内容。
- 过线：每考题 ≥30/40 且无致命穿帮；换题 ≥70/100。
- 判卷另有像素实测兜底（measure.mjs）：黑边有无/值域/唯一色数是量出来的，
  不是形容出来的——形容词会字面化（说"CRT 感"结果真画了扫描线）。
- 还原效果不还原内容：神似>形似，逼着你抄画反而低分。

## 6. 交付契约（/task/out/ 里必须有什么）

```
kit.js                  画材包本体（+你需要的配角文件，全部列进 kit.json.files）
kit.json                清单：{framework, deps:[{name,version,license}], files:[...],
                        cheat_sheet(四类组织,≤2k token), notes(配方≤14行:路线+弱点)}
scene-exam-1..N.html    考题场景（N=in/truth-*.png 的张数，逐张还原其画风构图）
scene-neutral.html      换题场景（圆+方块+波浪，同配方版本——别用旧参数应付）
package.json/.lock      有依赖时必交（版本钉精确：1.2.3 合法，^1.0/~2/latest 违法）
```

npm install 记得 `--ignore-scripts`（默认纪律，真需要构建脚本再单独放行）。
场景 HTML 里引 kit 用相对路径（`<script src="./kit.js">`），监工重渲只认这个布局。

## 7. 已知陷阱（配方笔记要重复的）

1. 换题场景必须与考题场景**同配方版本**——换题图停在旧参数会被纯形容词版反超。
2. RGB 色散是爆点专属特效，不可下放为元素填色；主体一律白线稿。
3. UI 墨水层取色锁真迹值域；新增色须有真迹出处。
4. 文字描述会字面化：一切色彩/质感结论以像素实测为准。
